# The Bhangra Institute — preview site

Temporary public preview of a proposed website for The Bhangra Institute (Manteca, CA). This is **not** the official site. Search engines are asked not to index it (`noindex`).

Live preview (GitHub Pages): https://gopi00007.github.io/bhangra-institute-preview/

## Take it down
Delete this repository, or turn off Pages: Settings → Pages → Unpublish.

## Update it
Replace `index.html` and push to the `main` branch. Pages usually refreshes within a minute or two.
